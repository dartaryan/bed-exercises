# Bed Exercises

A simple, mobile-first page of gentle bed exercises for a caregiver.

- Live page: https://dartaryan.github.io/bed-exercises/
- One file: `index.html` (inline CSS and JS, Google Fonts only).
- Each exercise card shows a video thumbnail. A tap loads a privacy-enhanced YouTube player
  (`youtube-nocookie.com`) that starts at that exercise and stops at its end. No players load
  until a tap, so the page stays fast on a phone.
- Videos belong to their creators (MD Anderson Cancer Center, NewYork-Presbyterian Hospital,
  More Life Health) and are played from YouTube.

This page is not medical advice. Follow the care team.
